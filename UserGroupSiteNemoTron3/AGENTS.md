# Repository Guidelines

Before modifying or reviewing C# files, read and follow:

- `.claude/rules/csharp.instructions.md`

Before modifying or reviewing Razor, Razor code-behind, or Razor CSS files, also read and follow:

- `.claude/rules/blazor.instructions.md`

Treat the YAML `paths` front matter in those files as applicability metadata. When instructions conflict, the more specific Blazor instructions take precedence.
